### 为什么不能对50米大范围始终执行16点/λ？

以10 GHz、λ≈29.98 mm、显示范围 X=50 m、Y=50 m、Z=60 m 为例：

- 每λ采8点：X/Y方向各约13,343个，Z方向约16,012个采样点；三切片理论总量约6.05亿采样点。
- 每λ采16点：X/Y各约26,686个，Z方向约32,023个；三切片理论总量约24.21亿采样点。
- 若每格存储12个复场实/虚分量（12×32-bit），后者仅数据数组就需要约116 GB，浏览器不适合。
- 当前软件大范围优先给出**概览**，需要看到稳定干涉细节时请使用**局部精细查看**；每λ采样点数仍只是经验值，不能代替正式网格收敛检验。

## 功能

- 三维源节点：独立 xyz（m）、初始相位（°）、参考功率（W，默认每路1 W；当前演示输入限制0–10 W）。
- 目标 T 使用独立 XYZ 坐标。YZ、XZ、XY 三个正交切片分别固定为 x=Tₓ、y=Tᵧ、z=T_z，修改目标后同步重新计算。原观察点 Q 和独立截面位置输入均已删除。
- 底部时域曲线直接读取目标 T 处各节点电场；局部精细查看也以 T 为中心。热图仍可鼠标悬浮读取空间场强。
- 三维几何预览支持拖动自由旋转、鼠标滚轮缩放和重置视角；右下角 XYZ 坐标系与旋转视角保持同步。
- 可调整 X/Y/Z 三张正交切片的位置、整体显示空间范围，查看单一三联图上的瞬时电场强度或瞬时功率通量。
- 可交互三维几何预览（旋转、缩放、视角坐标系）、各节点时域曲线、5倍鼠标放大镜、高清PNG和单切片CSV导出。
- `index.html` 主入口；`app3d.js` 用户交互；`physics3d.js` 三维场；`worker3d.js` 后台求解；`style3d.css` 论文风格界面；`legacy/` 旧版备份。

## 物理与数值限制

- 模型是**单元远场矩形口径方向图 + 各节点球面传播 + 瞬时矢量 E/H 叠加**；不涉及体素全波求解。
- `|S(t)|` 是瞬时坡印廷向量**模值**而非穿过某截面的有符号法向通量，也不是时间平均值。
- 单口径Fraunhofer界限内的远场表达式不可适用，软件在这一局部区域屏蔽相应贡献，**不代表真实电场为0**。
- 口面效率、方向图全角度功率归一化仍为简化假设。绝对 W/cm² 不可直接当作真实器件的校准数据。
- 不含反射、互耦、实际旁瓣、介质和目标散射；不连接RF设备，也不做自动相位优化或硬件跟踪。
