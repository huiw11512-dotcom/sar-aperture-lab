# Wave Lab · 三维正交切片版

在线入口：https://huiw11512-dotcom.github.io/sar-aperture-lab/wave-lab/

旧二维版：https://huiw11512-dotcom.github.io/sar-aperture-lab/wave-lab/legacy/

## 功能

- **三维源节点**：每路独立设置 x、y、z（m）、初始相位（°）、参考功率（W，默认1 W；当前低功率演示输入0–10 W）。
- **三维目标 T**：自由设置 xyz 坐标，虚拟口径朝向随 T 更新，场计算重新运行；不调整独立源的初始相位。
- **三维观察点 Q**：独立设置 xyz，点击 XY、XZ、YZ 中任意切片也可选择取样点；观察点不控制天线姿态。
- **三张正交切片合成一张图板**：X固定的 YZ、Y固定的 XZ、Z固定的 XY，位置分别设置，可切换观察瞬时电场模 `|E(t)|`（V/m）和瞬时坡印廷向量模 `|S(t)|`（W/cm²）。
- 不再显示周期平均功率密度图。附三维几何轴测预览、分节点时域曲线和5倍放大镜。
- **多分辨率计算**：320、512（默认）、768、1000，每档均是三张同尺寸的二维切片，因此1000表示3×100万网格点，而非1000³体素。计算在Web Worker中运行，时间播放使用缓存的复场相量。
- PNG导出整张三联切片科研图；CSV输出下拉框所选择的单张切片和当前显示变量。

## 数值模型与重要限制

- 采用每个天线单元的简化远场矩形口径方向图 `sinc(πau/λ)sinc(πbv/λ)`、球面传播距离及相位、局部电磁场矢量正交约束，然后叠加E/H并计算瞬时 `E×H`。
- `|S|` 是**瞬时坡印廷矢量的模**，不是穿过指定截面的有符号法向分量，也不是周期平均量。
- 所显示的 `|E|` 是瞬时合成电场矢量模；节点时域图显示观察点处主导笛卡尔电场分量（便于比较各节点相位和幅值）。
- 每个口径在离该天线**不足其保守Fraunhofer距离**的点处不再使用远场表达式，该局部贡献被屏蔽。这并不意味着这些位置真实场为零。
- 当前绝对通量仍是理想化功率增益模型的估计值：原版本的口面效率和方向图全空间归一化尚不严格一致，无法将绝对 W/cm² 数值视为真实硬件校准结果。
- 无互耦、材料、反射、真实天线旁瓣、实测标定或有限口径全波求解；场图密度可能因采样不足漏掉干涉峰值。
- 不连接任何射频硬件，不进行相位优化、自动闭环目标跟踪或高功率系统功率预算。

## 仓库

- `index.html`：统一页面
- `style3d.css`：浅色科研布局
- `physics3d.js`：独立纯函数的三维波场模型
- `worker3d.js`：后台计算三幅正交切片
- `app3d.js`：交互、三维场景预览、时域波形、图像与CSV导出
- `legacy/index.html`：改版前二维备份
- `validation/`：此前二维模型的数值检查记录；不等于三维模型的工程精度验证
