模型边界

这是可计算的系统级教学/方案仿真，不是特定 PA、LNA、混频器或天线的实测器件模型。采用矩形地面、逐散射单元复包络、常温接收噪声、简化 AM/AM、近似 IQ 失衡和量化；WebGL 用于任务场景可视化，不代表三维全波求解。RDA 是狭视场近似版本，BP 是主验证路径，二者的峰值强度不能在不做相同归一化时直接比较。

APERTURE LAB · 完整计算在当前浏览器内完成，不需要安装 Python 或下载工程包。本项目已通过公开 GitHub Pages 托管；宽幅为光学散射代理，局部 106m 为代表性相干 BP 仿真。
